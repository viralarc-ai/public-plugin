# 成效、流量塔台與連結數據

## 使用者如何查看成效

「自動化總覽」顯示專案回覆、瀏覽與按讚統計。「流量搭台」又稱流量塔台或
Watchtower，可選擇 Threads 貼文，檢視即時瀏覽、按讚、回覆、分享及衍生互動
指標。100 小時曲線頁籤標示尚未開放。開啟即時貼文畫面與讀取已儲存的自動化
指標，是不同的操作。

已設定追蹤連結的留言轉私訊流程提供「連結數據統計」：選擇連結、資料來源與
時間範圍後，查看點擊、估計訪客、最後存取，以及可用的地區、來源、裝置分布。

## ChatGPT 工作流程

1. 確認目標帳號與專案，以及問題是在問發送活動、自動回覆成效或連結活動。
2. 用 `get_automation_status` 讀取有限範圍的執行與發送紀錄。用
   `get_automation_insights` 讀取快取的 Threads／Instagram 回覆彙整與追蹤
   連結點擊；這些彙整不包含 Facebook 自動回覆成效。保留時間、涵蓋範圍與
   專案截斷資訊，不要說成完整或即時資料。
3. 區分發布數量與互動指標。資料無法取得時應說明，讀取失敗不代表數值為零。
4. 一般 MCP 工具集不提供流量塔台的即時更新、曲線，或全部點擊圖表的細分
   控制。需要這些檢視時引導使用者到對應介面，不要虛構即時刷新或指標工具。

要啟用追蹤，先在留言自動化設定實際連結，並確認帳號能力與方案權限。不要
為了查看統計而取代既有追蹤連結，編輯與讀取是不同操作。

範例：「比較這兩個自動化的快取回覆成效與追蹤連結點擊，並說明可用資料的
限制。」
