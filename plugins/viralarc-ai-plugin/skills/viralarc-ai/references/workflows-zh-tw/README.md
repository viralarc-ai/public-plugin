# ViralArc 功能工作流程

依使用者要求，只讀取需要的模組。每份指南說明實際介面的選項，以及 ChatGPT
如何透過此外掛完成支援的工作。品牌與多語名稱請見[常用詞彙](../common-terms.md)。

| 模組 | 適用情境 |
| --- | --- |
| [統籌執行與操作恢復](orchestration.md) | ChatGPT 接手執行、定期任務、暫停重複自動化與處理不確定結果。 |
| [一般海巡](topic-patrol.md) | 搜尋篩選、專案設定、回覆草稿、發送與搜尋結果加入客戶名單。 |
| [輿情追蹤](reputation-monitoring.md) | 只追蹤的搜尋、情緒與風險判斷、保留發現及後續處理。 |
| [貼文管理](posts-and-comments.md) | 自有貼文、較早紀錄、留言、單則回覆與留言者匯入。 |
| [留言自動化](comment-automation.md) | Threads 回覆、Instagram／Facebook 留言轉私訊、追蹤後解鎖、連結追蹤與複製設定。 |
| [提及](mentions.md) | 篩選專案、同步與處理、審核、範本、安全回覆及名單收錄。 |
| [客戶名單](lead-lists.md) | 名單與項目、狀態標籤備註、偏好設定、來源匯入、分享及 CSV 下載。 |
| [表單製造所](forms.md) | 題型、條件、設定、版本、草稿發布與已送出回覆。 |
| [酷碰城市](couponcity.md) | 優惠券草稿與發布、領取規則、渠道追蹤、人員權限、成效及顧客核銷碼操作。 |
| [社群連結](accounts-and-connections.md) | 選擇帳號、重新連接、LINE 與 OAuth 授權應用程式。 |
| [品牌資料](business-profiles.md) | 品牌脈絡、資料設定、帳號指派與創作者資料的差別。 |
| [自動化總覽與回覆紀錄](automations-and-reply-history.md) | 啟停刪除、草稿、佇列發送、取消及結果查核。 |
| [成效資料](insights.md) | 快取自動化指標、流量塔台與連結數據。 |
| [訂閱管理與權限](billing-and-access.md) | 方案、點數、成功付款、功能能力及支援。 |
| [其他功能區](other-product-areas.md) | CreatorOS、行銷短網址、大家投票趣與受限制的介面流程。 |

變更前先選定實際帳號與已儲存的對象，讀取目前設定並保留未指定的值。參數
依目前工具規格，平台差異依帳號實際能力，成功與否依回傳結果判斷。使用者
要求在原生編輯器操作時，應引導至該介面；MCP 寫入不會開啟或操作編輯器。

兩種海巡工作流程都可以在搜尋結果回來後，把選定結果加入客戶名單，不必
先回覆。兩者的選取標準不同：一般海巡看互動是否適合，輿情追蹤看品牌或
議題是否相關。
