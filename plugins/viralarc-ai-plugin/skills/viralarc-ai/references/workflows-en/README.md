# ViralArc feature workflows

Read only the modules needed for the user's request. Each guide explains the
relevant UI choices and how ChatGPT carries out supported work through this
plugin. Use [common terms](../common-terms.md) for localized brand names.

| Module | Use it for |
| --- | --- |
| [Orchestration and recovery](orchestration.md) | ChatGPT-led runs, recurring tasks, pausing overlapping automation, and uncertain actions. |
| [Topic Patrol](topic-patrol.md) | Search/filter, project settings, reply drafts, sending, and adding returned results to a lead list. |
| [Reputation Monitoring](reputation-monitoring.md) | Tracking-only searches, sentiment/risk assessment, saved findings, and follow-up. |
| [Post Manager](posts-and-comments.md) | Owned posts, older history, comments, precise replies, and commenter imports. |
| [Comment automation](comment-automation.md) | Threads replies, Instagram/Facebook comment-to-DM, follow gates, tracked links, and copying setups. |
| [Mentions](mentions.md) | Filtered mention projects, sync/processing, review, templates, safe replies, and lead capture. |
| [Lead List](lead-lists.md) | Lists and entries, statuses/tags/notes, preferences, source imports, sharing, and CSV downloads. |
| [Form Studio](forms.md) | Question types, conditions, settings, revisions, draft/publish, and submitted responses. |
| [CouponCity](couponcity.md) | Coupon drafts/publication, claim rules, tracked channels, staff roles, reports, and explicit customer-code redemption. |
| [Accounts and connections](accounts-and-connections.md) | Account selection, reconnection, LINE, and OAuth-connected apps. |
| [Business Profile](business-profiles.md) | Brand context, profile settings, account assignment, and Creator Profile distinctions. |
| [Automations and Reply History](automations-and-reply-history.md) | Lifecycle controls, drafts, queued delivery, cancellation, and receipt recovery. |
| [Insights](insights.md) | Cached automation metrics, Traffic Stage, and link analytics. |
| [Billing and access](billing-and-access.md) | Plans, credits, successful payments, capabilities, and support. |
| [Other product areas](other-product-areas.md) | CreatorOS, Marketing Short Links, Vote Together, and restricted UI workflows. |

Select the actual account and saved objects before making changes. Read current
settings and preserve omitted values. Use live tool schemas for parameters and
account capabilities for provider-specific behavior. Describe success only
from returned results. If the user asks to use a native editor, guide them to
that UI; an MCP write does not open or operate it.

Both Topic Patrol workflows can add selected results to a lead list after search
returns, independently of whether any reply is sent. They use different selection
criteria: interaction suitability for normal patrol, brand/issue relevance for
reputation monitoring.
