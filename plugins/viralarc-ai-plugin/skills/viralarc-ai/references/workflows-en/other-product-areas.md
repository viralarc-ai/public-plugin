# Other ViralArc product areas

These names can appear in a user's request even though their full controls are
outside this plugin's normal-agent tools. Explain the relevant UI workflow and
use available support guidance. Do not claim to operate a missing tool.

## CreatorOS

Open the CreatorOS workspace and choose a Creator Profile. The board moves work
through **Idea Pool → Writing content → Creating → Published**. Quick capture
adds an idea. **Use Reel** accepts an Instagram Reel URL and imports transcript
analysis as an idea. **Scripting** opens from a project card dropped onto the app.
**Teleprompter** takes the script into recording. **Auto reply** selects an owned
published Instagram/Facebook post and opens comment-auto-reply setup.

Ask which stage and project the user means. CreatorOS has its own assistant and
app controls; those operations, Reel transcription, script generation, and
creator-profile tools are not exposed by this plugin. The board's Published
column alone is not a social-platform publication receipt. Existing normal-agent
comment tools can manage a supported owned post after it has been selected; see
[comment automation](comment-automation.md).

## Marketing Short Links

Open **Marketing Short Links**, add a link, give it a name and valid destination,
then copy the generated short URL. Selecting a link exposes the relevant
analytics. Dedicated short-link creation and administration are not in the MCP
catalog. DM tracked-link configuration and cached click metrics are narrower
capabilities; see [insights](insights.md).

## Vote Together

The voting workspace separates entries from voting results. Project setup asks
for a title, description, entry/vote limits per person, who may submit, public
or unlisted visibility, eligible voters, result visibility, ballot edit policy,
self-voting, and optional submission/voting windows. These choices affect access
and voting behavior. Create/configure projects, upload entries, and cast ballots
through Vote Together's UI; this plugin has no voting actions.

## Restricted or unfinished areas

The separate Keyword Tracking page has an unfinished keyword-creation workflow;
use [reputation monitoring](reputation-monitoring.md) for the supported
ChatGPT-led search-and-assessment process. AI Text Naturalizer and Pending Posts
are developer-only surfaces. Marketplace, enterprise campaign review, organization
administration, and other specialty services have their own permissions and
workflows. Do not infer access or an action from a navigation label alone.

Example: “Where do I set a voting deadline, and can this plugin change it?”
Explain the Vote Together settings and its UI-only boundary.
